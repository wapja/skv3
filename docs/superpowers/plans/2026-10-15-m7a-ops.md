# M7a Ops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the kit's operations layer (spec §4.9 and the System page of §6.5):
- the authenticated `/health-check` endpoint
- the backups module on spatie/laravel-backup
- the scheduler
- the System page

On top of that:
- tag audit entries written from the command line
- keep passwords out of process arguments
- guard `skv:install`, `skv:bootstrap` and the demo seeder outside local development
- harden the doctor where the System page reuses it

**Architecture:**
- **One set of check classes.** Health results are doctor checks (`App\Setup\Doctor\Check`). Two new ones, `failed-jobs` and `last-backup`, join the existing `database`, `queue` and `mail` checks.
- **`HealthReport`** runs those five against a detection-free `DoctorContext`. It caches the result on the `file` cache store, so a database outage still answers.
- **`/health-check`** is registered outside the `web` group. It is throttled on the file store and authorised by `X-Health-Check-Key`. It returns the cached report as JSON: 200 when healthy, 503 when a check fails.
- **The System page** (`system.index`, central hosts, `system.health`) shows:
  - the same cached report
  - the backups
  - the schedule with a heartbeat
  - an on-demand run of the doctor checks that start no child process
- **Backups** use spatie/laravel-backup 10.3: database only, encrypted, on a dedicated `backups` disk, failure-only mail, and `pg_dump` found the doctor's way. Encryption fails closed: the doctor's `backup-password` row and the `last-backup` health check fail while backups would be written unencrypted (CD-10).
- **The CLI.** Audit entries written while an Artisan command runs carry `properties.via = console` and the command name, through Laravel's hidden `Context`. Secrets reach commands on standard input or in a file, never in argv.

**Tech Stack:** PHP 8.4, Laravel 13.35, Livewire 4.4 (multi-file components), Flux 2.20 (free), **spatie/laravel-backup ^10.3 (new, CD-2)**, spatie/laravel-activitylog 5.1, laravel/prompts 0.3, Pest 5.3 with pest-plugin-browser 5.1, Larastan 3 level 8, PostgreSQL 18 (Herd), SQLite.

- Facts verified for this plan (2026-10-15; vendor reads, the 10.3.3 source of spatie/laravel-backup):
  - **spatie/laravel-backup 10.3.3** requires `php ^8.3`, `ext-zip`, `illuminate/* ^12.40|^13.0`.
    - `Spatie\Backup\Config\Config` is a scoped binding built with `Config::fromArray(config('backup'))`. It merges the package's defaults under the app's `backup` / `notifications` / `cleanup` arrays. `monitor_backups` replaces the default wholesale.
    - `NotificationMailConfig::fromArray()` throws when a `to` address is not a valid email. spatie's `BackupCommand`, `ListCommand` and `MonitorCommand` take the `Config` in their constructors and are built whenever Artisan boots, so an invalid `BACKUP_NOTIFY_EMAIL` would break every `php artisan` command: `config/backup.php` lets only a valid address through.
    - Encryption fails open: a blank password becomes null and the zip is written unencrypted, and `'encryption' => 'default'` means none when `ZipArchive::EM_AES_256` is undefined. Hence the `backup-password` doctor check and `LastBackupCheck`'s encryption guard (CD-10).
    - Every notification class key must stay in `notifications.notifications`; a channel list of `[]` silences one.
    - `BackupDestination::create(string $disk, string $backupName)` never throws. Its methods: `isReachable()`, `newestBackup(): ?Backup` (`Backup::date(): Carbon`, parsed from the file name `Y-m-d-H-i-s.zip`), `backups()`, `usedStorage(): float` (bytes).
    - `DbDumperFactory` maps `config('database.connections.<name>.dump')` keys to setters, so `dump_binary_path` calls `setDumpBinaryPath()` (a directory).
    - Commands: `backup:run {--only-db}`, `backup:clean`, `backup:monitor`, `backup:list`.
  - **Laravel 13.35:**
    - `withRouting(..., then: fn () => …)` registers routes outside every middleware group; only global middleware runs.
    - `Context::addHidden($key, $value)`, `getHidden($key)` and `forgetHidden($key)` exist. Hidden context travels into queued jobs and is never written to logs. A queue worker *replaces* the context for every job (`Context::hydrate()` flushes first).
    - `Schedule::events()` returns the registered events. Each has public `$expression`, `$command`, `$onOneServer` and `$withoutOverlapping`, plus `filtersPass($app)` and `nextRunDate()`.
    - `Illuminate\Queue\Failed\CountableFailedJobProvider::count()` is implemented by the database failed-job providers.
    - `CommandStarting` / `CommandFinished` fire for nested `Artisan::call()`s too, but under PHPUnit/Pest only in tests that use `Illuminate\Foundation\Testing\WithConsoleEvents`: the console kernel skips `rerouteSymfonyCommandEvents()` while `runningUnitTests()` (`Foundation/Console/Kernel.php:145-149`). A test without the trait dispatches the event by hand (`event(new CommandStarting(...))`, as `ConfigurePgDumpTest` and `TenantScopeTest` do) or sees no listener run.
    - Symfony `Input::setStream()` / `StreamableInputInterface::getStream()` let a command read piped standard input; `Artisan::call()` cannot pass a stream.
  - **The kit:**
    - `DoctorContext::forApplication()` runs `Detector::detect()`, which starts `herd` processes and probes PostgreSQL. Web code must not use it (RL-2).
    - `HandoffToken` is the only `Prunable` model.
    - `routes/console.php` schedules nothing yet.
    - Nothing in `config/` reads `HEALTH_CHECK_KEY`; `env()` outside `config/` is forbidden (`tests/Arch/KitRulesTest.php`).

## Controller decisions (owner delegation, 2026-10-15)

- **CD-1, the split:** M7 is split into M7a (this plan, ops), M7b (setup hardening) and M7c (§6.6 extras + security hardening), as M6 was split into M6a/M6b. Each plan stays reviewable, and each milestone keeps its own gate.
- **CD-2, the dependency:** `spatie/laravel-backup ^10.3`. §4.9 names its commands (`backup:run --only-db`, `backup:clean`, `backup:monitor`) and its destination API. 10.3.3 supports Laravel 13 and PHP 8.4. This is the milestone's only new dependency.
- **CD-3, failed jobs:** the health "queue" entry is two checks:
  - `queue`: the connection works and its jobs table exists (unchanged)
  - `failed-jobs`:
    - `fail` when the failed-jobs table is missing
    - `warn` when failed jobs are stored
    - `pass` otherwise
  - So a stored failed job never turns the endpoint into a 503. `queue:prune-failed` clears old ones daily.
- **CD-4, last backup:** `last-backup` is a health check, not a doctor check. On a fresh install it would fail until the first nightly backup, and §12 criterion 2 needs a doctor without `fail` after setup. The System page shows it with the health results.
- **CD-5, caching and throttling on the file store:** the health report is cached for `skv.health_check.cache_seconds` (30) on the `file` cache store. `/health-check` is throttled by its own middleware on the same store (60 per minute per IP). Both work while the database, and so the default `database` cache store, is down. A database outage therefore answers 503 with JSON instead of a 500.
- **CD-6, the backup name and disk:**
  - The backup name is `Str::slug(APP_NAME)`, falling back to `app`.
  - The archives go to a dedicated local disk `backups` (`storage/app/backups`), not the `local` disk that serves `storage/app/private`.
  - Production can point `backups` at S3 in `config/filesystems.php`.
- **CD-7, the CLI actor:**
  - **The tag.** Every audit entry written while an Artisan command runs carries `properties.via = 'console'` and `properties.command = '<name>'`. A hidden `Context` value set on `CommandStarting` carries it. Queue workers and the scheduler's own runner are left out, so jobs keep the context they were dispatched with.
  - **The viewer** shows "Command line" for such an entry without a causer, and ":name via the command line" with one.
  - **The actor.** `skv:create-organisation` keeps acting as a super admin, because `CreateOrganisation` authorises the actor. `--as=<email>` picks which one; the default is the oldest active one.
- **CD-8, secrets on standard input:**
  - `skv:create-super-admin --password-stdin` reads the password from the first line of standard input. `--password=` is removed, so a script that still passes it fails loudly instead of leaking.
  - `skv:install --answers=` takes inline JSON, `@path` (a file) or `-` (standard input). An inline value with a non-empty `super_admin_password` is refused before anything runs.
- **CD-9, production guards** (supersedes DEC-31's "`skv:install` gets no production guard"):
  - **`skv:install`** refuses to run when the app is in production. A fresh server still runs it, because `.env.example` ships `APP_ENV=local`.
  - **`skv:bootstrap`**, for a target `.env` with `APP_ENV=production`, only copies `.env`, generates `APP_KEY` and fills every blank `EnvironmentStep::GENERATED` secret (`HEALTH_CHECK_KEY`, `BACKUP_ARCHIVE_PASSWORD`; CD-10): no Herd `APP_URL`, no SQLite migration, no setup token.
  - **The demo seeder** runs only in `local` and `testing`, and `DemoSeeder` refuses everywhere else. `skv:install` refuses `start_with=demo` outside `local` / `testing` right after the answers validate, so a staging install never stops half-way in the database step.
- **CD-10, fail-closed backup encryption:** spatie/laravel-backup writes an unencrypted zip when `BACKUP_ARCHIVE_PASSWORD` is blank, or when PHP's zip has no AES-256, and reports success. Two layers close that:
  - **The doctor check** `backup-password` (`App\Setup\Doctor\Checks\BackupPasswordCheck`): skipped while the backups module is off, `fail` while the context's `.env` has a blank `BACKUP_ARCHIVE_PASSWORD`. Its safe repair (`skv:doctor --fix`) writes a random one, never printed. It starts no process, so the System page runs it too (RL-7).
  - **The health check** `last-backup` fails while `config('backup.backup.password')` is blank or `ZipArchive::EM_AES_256` is undefined, so `/health-check` answers 503 instead of reporting plaintext backups as healthy.
  - **The password itself:** besides setup's environment step, the production bootstrap generates it too (CD-9).

## Rulings

- **RL-1 (health checks are doctor checks):**
  - `App\Support\Health\HealthReport::checks()` returns, in this order: `DatabaseCheck`, `QueueCheck`, `FailedJobsCheck`, `MailCheck`, `LastBackupCheck`.
  - `HealthReport` runs them through `Doctor::run()`, so one throwing check is a `fail` naming only its exception class, as in the doctor.
  - `failed-jobs` also joins `Doctor::checks()`, after `queue`; `last-backup` does not (CD-4). `backup-password` is a doctor check only, after `health-check-key` (CD-10).
- **RL-2 (a detection-free context):** `DoctorContext::withoutDetection(?string $basePath = null): self` = `new self($basePath ?? base_path(), app(Toolchain::class), Detection::none(), null)`.
  - `HealthReport`, the System page and `ConfigurePgDump` use it, because `forApplication()` starts `herd` processes and a PostgreSQL probe.
  - Their constructors take an optional base path, so tests point them at a sandbox instead of the repository's `.env`.
- **RL-3 (the report shape):**
  - `HealthReport::run()` returns `array{checked_at: string, healthy: bool, checks: array<string, array{label: string, status: string, message: string}>}`.
    - `checked_at` is ISO-8601 (`now()->toIso8601String()`).
    - `healthy` is `Doctor::isGreen()`.
    - `status` is the `CheckStatus` value.
    - No `fix` field: the endpoint is public behind a key, and the fix commands name paths.
  - `cached()` returns the cached report or runs and caches it; `refresh()` runs and caches it. The cache key carries the locale (`health:report:<locale>`), because labels and messages are translated when the report runs: `/health-check` (no locale middleware, so `APP_LOCALE`) and a super admin's System page in another language never share a report.
- **RL-4 (`pg_dump`):**
  - `config/database.php`'s `pgsql` connection gets `'dump' => ['dump_binary_path' => env('PG_DUMP_BINARY_PATH', '')]`.
  - On `CommandStarting` for `backup:run`, `App\Support\Backups\ConfigurePgDump` fills an empty `dump_binary_path` with the directory of the `pg_dump` that `PostgresBinaries::find()` returns (`.env`, then the toolchain PATH, then Herd's newest PostgreSQL service).
  - A cron job has no Herd PATH, so this is what lets the nightly backup find Herd's `pg_dump`.
  - Under Pest, `CommandStarting` fires only with `WithConsoleEvents` (see the facts), so `ConfigurePgDumpTest` dispatches the event by hand and `BackupRunTest` sets `dump_binary_path` itself.
- **RL-5 (the endpoint):**
  - `GET /health-check`, named `health-check`, registered in `withRouting(then:)` with only `App\Http\Middleware\ThrottleHealthChecks`. No session, cookies, tenancy, setup mode or locale middleware.
  - `HealthCheckController` returns:
    - 403 `{"message":"Forbidden."}` when `config('skv.health_check.key')` is blank, the header is missing, or `hash_equals()` fails
    - otherwise the cached report with 200 (healthy) or 503, and `Cache-Control: no-store`
  - A request on a tenant subdomain, known or not, gets the same answer: no tenant is resolved.
- **RL-6 (the System page):**
  - `pages::system.index` at `/system`, named `system.index`, inside `Route::central()` with `->can(Permission::SystemHealth)`.
  - **The navigation item** is `new NavigationItem('system.index', 'System status', 'server-stack', Permission::SystemHealth, 'system.*', NavigationGroup::System, centralOnly: true)`, after the activity log.
  - **The sections:**
    - **Health** (the cached report and its time, a *Refresh* action)
    - **Backups:**
      - module off → the reason
      - otherwise per destination: disk, reachable, number of backups, newest backup, used storage
    - **Schedule:**

```php
/**
```

```php
    /** @param  string|null  $basePath  the project whose .env is read; tests pass a sandbox */
```

```php
<?php

declare(strict_types=1);

namespace App\Setup\Doctor\Checks;

use App\Setup\Doctor\Check;
use App\Setup\Doctor\CheckResult;
use App\Setup\Doctor\DoctorContext;
use Illuminate\Queue\Failed\CountableFailedJobProvider;
use Illuminate\Queue\Failed\FailedJobProviderInterface;
use Illuminate\Support\Facades\Schema;
use Throwable;

/**
 * §4.9, CD-3: failed jobs. Fails only when the database failer's table is missing; stored failed jobs warn (the
 * schedule prunes them daily), so they never turn /health-check into a 503.
 */
final readonly class FailedJobsCheck implements Check
{
    public function key(): string
    {
        return 'failed-jobs';
    }

    public function label(): string
    {
        return __('Failed jobs');
    }

    public function run(DoctorContext $context): CheckResult
    {
        $driver = (string) config('queue.failed.driver', 'null');

        if ($driver === 'null') {
            return CheckResult::pass(__('Failed jobs are not stored'));
        }

        if (in_array($driver, ['database', 'database-uuids'], true)) {
            $table = (string) config('queue.failed.table', 'failed_jobs');
            $connection = config('queue.failed.database');

            try {
                $exists = Schema::connection(is_string($connection) ? $connection : null)->hasTable($table);
            } catch (Throwable) {
                $exists = false;
            }

            if (! $exists) {
                return CheckResult::fail(__('The :table table is missing', ['table' => $table]), 'php artisan migrate');
            }
        }

        $count = $this->storedFailedJobs(app(FailedJobProviderInterface::class));

        return $count === 0
            ? CheckResult::pass(__('No failed jobs'))
            : CheckResult::warn(trans_choice(':count failed job is stored|:count failed jobs are stored', $count), 'php artisan queue:retry all');
    }

    public function fix(DoctorContext $context): ?CheckResult
    {
        return null;
    }

    /**
     * The number of stored failed jobs. Typed as the contract: Larastan resolves the container binding to the
     * database provider and would flag the instanceof as always true; drivers without count() fall back to all().
     */
    private function storedFailedJobs(FailedJobProviderInterface $failer): int
    {
        return $failer instanceof CountableFailedJobProvider ? $failer->count() : count($failer->all());
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Setup\Doctor\Checks;

use App\Setup\Doctor\Check;
use App\Setup\Doctor\CheckResult;
use App\Setup\Doctor\DoctorContext;
use App\Support\Backups\BackupDestinations;
use App\Support\Skv;
use Illuminate\Support\Facades\Date;
use ZipArchive;

/**
 * §4.9, CD-4: every backup destination is reachable and holds a backup newer than the monitor's maximum age.
 * Skipped while the backups module is off (§6.8, never a 503). A health check, not a doctor check: a fresh install
 * has no backup until the first night. Fails while the backups would be written unencrypted (CD-10): the package
 * silently skips encryption for a blank password or a zip without AES-256.
 */
final readonly class LastBackupCheck implements Check
{
    public function key(): string
    {
        return 'last-backup';
    }

    public function label(): string
    {
        return __('Last backup');
    }

    public function run(DoctorContext $context): CheckResult
    {
        if (! Skv::moduleEnabled('backups')) {
            return CheckResult::skipped(__('The backups module is off'));
        }

        if ((string) config('backup.backup.password', '') === '' || ! defined(ZipArchive::class.'::EM_AES_256')) {
            return CheckResult::fail(__('Backups are not encrypted: BACKUP_ARCHIVE_PASSWORD is empty or this PHP zip has no AES-256'), 'php artisan skv:doctor --fix');
        }

        $destinations = BackupDestinations::all();

        if ($destinations === []) {
            return CheckResult::fail(__('No backup disk is configured'), 'config/backup.php');
        }

        $oldestAllowed = Date::now()->subDays(BackupDestinations::maximumAgeInDays());
        $newestDate = null;

        foreach ($destinations as $destination) {
            if (! $destination->isReachable()) {
                return CheckResult::fail(__('The backup disk :disk cannot be reached', ['disk' => $destination->diskName()]), 'config/filesystems.php');
            }

            $newest = $destination->newestBackup();

            if ($newest === null) {
                return CheckResult::fail(__('There is no backup on :disk yet', ['disk' => $destination->diskName()]), 'php artisan backup:run --only-db');
            }

            if ($newest->date()->lt($oldestAllowed)) {
                return CheckResult::fail(
                    __('The last backup on :disk is from :time', ['disk' => $destination->diskName(), 'time' => $newest->date()->diffForHumans()]),
                    'php artisan backup:run --only-db',
                );
            }

            $newestDate = $newestDate === null || $newest->date()->gt($newestDate) ? $newest->date() : $newestDate;
        }

        // The list is non-empty and every iteration returns or sets $newestDate, so PHPStan knows it is a date here.
        return CheckResult::pass(__('The last backup is from :time', ['time' => $newestDate->diffForHumans()]));
    }

    public function fix(DoctorContext $context): ?CheckResult
    {
        return null;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Support\Health;

use App\Setup\Doctor\Check;
use App\Setup\Doctor\Checks\DatabaseCheck;
use App\Setup\Doctor\Checks\FailedJobsCheck;
use App\Setup\Doctor\Checks\LastBackupCheck;
use App\Setup\Doctor\Checks\MailCheck;
use App\Setup\Doctor\Checks\QueueCheck;
use App\Setup\Doctor\Doctor;
use App\Setup\Doctor\DoctorContext;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Date;

/**
 * The health results of §4.9 (RL-1, RL-3): the doctor's database, queue, failed-jobs and mail checks plus the last
 * backup, run against a context without detection (RL-2) and cached briefly on the ops store (CD-5), once per locale
 * because labels and messages are translated when it runs. /health-check and the System page show the same report.
 * No fix commands: the report leaves the server.
 *
 * @phpstan-type Report array{checked_at: string, healthy: bool, checks: array<string, array{label: string, status: string, message: string}>}
 */
final readonly class HealthReport
{
    public const string CACHE_KEY = 'health:report';

    /**
     * @param  list<Check>|null  $checks  the checks to run; null runs the kit's (tests pass their own)
     * @param  string|null  $basePath  the project whose .env the checks read; tests pass a sandbox
     */
    public function __construct(private ?array $checks = null, private ?string $basePath = null) {}

    /** @return list<Check> */
    public function checks(): array
    {
        return $this->checks ?? [new DatabaseCheck, new QueueCheck, new FailedJobsCheck, new MailCheck, new LastBackupCheck];
    }

    /** @return Report */
    public function run(): array
    {
        $checks = $this->checks();
        $results = new Doctor($checks)->run(DoctorContext::withoutDetection($this->basePath));
        $rows = [];

        foreach ($checks as $check) {
            $result = $results[$check->key()];
            $rows[$check->key()] = ['label' => $check->label(), 'status' => $result->status->value, 'message' => $result->message];
        }

        return [
            'checked_at' => Date::now()->toIso8601String(),
            'healthy' => Doctor::isGreen($results),
            'checks' => $rows,
        ];
    }

    /** @return Report the cached report, or a fresh one that is then cached */
    public function cached(): array
    {
        $cached = Cache::store($this->store())->get($this->key());

        if (is_array($cached) && isset($cached['checked_at'], $cached['healthy'], $cached['checks'])) {
            /** @var Report $cached */
            return $cached;
        }

        return $this->refresh();
    }

    /** @return Report a fresh report, cached for the next requests */
    public function refresh(): array
    {
        $report = $this->run();
        Cache::store($this->store())->put($this->key(), $report, max(1, (int) config('skv.health_check.cache_seconds', 30)));

        return $report;
    }

    /** The cache key of the current locale's report: labels and messages are translated when the report runs. */
    public function key(): string
    {
        return self::CACHE_KEY.':'.app()->getLocale();
    }

    private function store(): string
    {
        return (string) config('skv.ops_cache_store', 'file');
    }
}
```

Likewise `FailedJobsCheck` takes the failer as the contract in `storedFailedJobs()` (an `instanceof` on `app(...)` is `instanceof.alwaysTrue`), and `LastBackupCheck` ends without a nullsafe call (`nullsafe.neverNull`). Do not "simplify" these back.

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Cache\RateLimiter;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;
use Symfony\Component\HttpFoundation\Response;

/**
 * Throttles /health-check per address on the ops cache store (CD-5), not the default database store the
 * `throttle` middleware uses, so a database outage is reported as a 503 instead of failing the limiter.
 */
final readonly class ThrottleHealthChecks
{
    public const int PER_MINUTE = 60;

    /** @param  Closure(Request): Response  $next */
    public function handle(Request $request, Closure $next): Response
    {
        $limiter = new RateLimiter(Cache::store((string) config('skv.ops_cache_store', 'file')));
        $key = 'health-check:'.$request->ip();

        if ($limiter->tooManyAttempts($key, self::PER_MINUTE)) {
            return new JsonResponse(['message' => 'Too Many Attempts.'], 429, ['Retry-After' => (string) $limiter->availableIn($key)]);
        }

        $limiter->hit($key, 60);

        return $next($request);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use App\Support\Health\HealthReport;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

/**
 * GET /health-check (§4.9, RL-5): authorised only by the X-Health-Check-Key header, compared with hash_equals();
 * a blank configured key always answers 403. Returns the cached health report: 200 when healthy, 503 when a check
 * fails. Registered outside the web group, so it carries no session, cookie, tenant or locale.
 */
final readonly class HealthCheckController
{
    public function __invoke(Request $request, HealthReport $report): JsonResponse
    {
        $key = (string) config('skv.health_check.key', '');
        $given = $request->header('X-Health-Check-Key');

        if ($key === '' || ! is_string($given) || ! hash_equals($key, $given)) {
            return new JsonResponse(['message' => 'Forbidden.'], 403, ['Cache-Control' => 'no-store']);
        }

        $result = $report->cached();

        return new JsonResponse($result, $result['healthy'] ? 200 : 503, ['Cache-Control' => 'no-store']);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Support\Scheduler;

use Carbon\CarbonImmutable;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Date;

/**
 * The scheduler's heartbeat (RL-8): the schedule stores the time every minute on the ops store, and the System page
 * shows it, so a missing cron entry is visible.
 */
final readonly class Heartbeat
{
    public const string CACHE_KEY = 'scheduler:heartbeat';

    public function beat(): void
    {
        Cache::store($this->store())->forever(self::CACHE_KEY, Date::now()->toIso8601String());
    }

    public function last(): ?CarbonImmutable
    {
        $beat = Cache::store($this->store())->get(self::CACHE_KEY);

        return is_string($beat) ? CarbonImmutable::parse($beat) : null;
    }

    private function store(): string
    {
        return (string) config('skv.ops_cache_store', 'file');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Support\Health;

use App\Setup\Doctor\Check;
use App\Setup\Doctor\Doctor;
use App\Setup\Doctor\DoctorContext;

/**
 * The doctor checks the System page runs on demand (RL-7): the ones that start no child process and open no network
 * connection other than the mail probe, run without a detection (RL-2). Their repairs are not offered on the page;
 * php artisan skv:doctor --fix runs them.
 */
final readonly class SystemChecks
{
    /** @var list<string> */
    public const array KEYS = [
        'php', 'gd', 'app-key', 'marker', 'database', 'migrations', 'permissions', 'organisation-admin-role',
        'super-admin', 'super-admin-badges', 'session-driver', 'authenticate-session', 'health-check-key',
        'backup-password', 'assets', 'mail', 'pg-dump', 'queue', 'failed-jobs', 'storage-link',
    ];

    /** @param  string|null  $basePath  the project whose .env the checks read; tests pass a sandbox */
    public function __construct(private ?string $basePath = null) {}

    public function doctor(): Doctor
    {
        return new Doctor(array_values(array_filter(
            new Doctor()->checks(),
            fn (Check $check): bool => in_array($check->key(), self::KEYS, true),
        )));
    }

    /** @return list<array{key: string, label: string, status: string, message: string}> in the doctor's order */
    public function rows(): array
    {
        $doctor = $this->doctor();
        $results = $doctor->run(DoctorContext::withoutDetection($this->basePath));

        return array_map(fn (Check $check): array => [
            'key' => $check->key(),
            'label' => $check->label(),
            'status' => $results[$check->key()]->status->value,
            'message' => $results[$check->key()]->message,
        ], $doctor->checks());
    }
}
```

```php
use Livewire\Attributes\Computed;
use Livewire\Attributes\Locked;
use Livewire\Attributes\Title;
use Livewire\Component;

new #[Title('System status')] class extends Component
{
    /** @var list<array{key: string, label: string, status: string, message: string}>|null the last on-demand doctor run (RL-6) */
    #[Locked]
    public ?array $doctorRows = null;

    /**
     * Mount the component.
     */
    public function mount(): void
    {
        Gate::authorize(Permission::SystemHealth);
    }

    /** Runs the health checks again and caches the new report (§4.9). */
    public function refreshHealth(): void
    {
        Gate::authorize(Permission::SystemHealth);

        app(HealthReport::class)->refresh();
        unset($this->health);
    }

    /** Runs the web-safe doctor checks (RL-7). */
    public function runDoctor(): void
    {
        Gate::authorize(Permission::SystemHealth);

        $this->doctorRows = app(SystemChecks::class)->rows();
    }

    /**
     * The cached health report as display rows; PHP code calls this method, never the magic computed property.
     *
     * @return array{healthy: bool, checked: string, rows: list<array{key: string, label: string, status: string, color: string, message: string}>}
     */
    #[Computed]
    public function health(): array
    {
        $report = app(HealthReport::class)->cached();
        $rows = [];

        foreach ($report['checks'] as $key => $check) {
            $status = CheckStatus::from($check['status']);
            $rows[] = ['key' => $key, 'label' => $check['label'], 'status' => $status->label(), 'color' => $status->color(), 'message' => $check['message']];
        }

        return ['healthy' => $report['healthy'], 'checked' => Carbon::parse($report['checked_at'])->diffForHumans(), 'rows' => $rows];
    }

    /**
     * @return array{enabled: bool, destinations: list<array{disk: string, reachable: bool, count: int, newest: ?string, size: ?string}>}
     */
    #[Computed]
    public function backups(): array
    {
        if (! Skv::moduleEnabled('backups')) {
            return ['enabled' => false, 'destinations' => []];
        }

        $destinations = [];

        foreach (BackupDestinations::all() as $destination) {
            $reachable = $destination->isReachable();
            $newest = $reachable ? $destination->newestBackup() : null;
            $destinations[] = [
                'disk' => $destination->diskName(),
                'reachable' => $reachable,
                'count' => $reachable ? $destination->backups()->count() : 0,
                'newest' => $newest?->date()->diffForHumans(),
                'size' => $reachable ? Number::fileSize($destination->usedStorage()) : null,
            ];
        }

        return ['enabled' => true, 'destinations' => $destinations];
    }

    /**
     * @return array{heartbeat: ?string, tasks: list<array{task: string, expression: string, next: string, active: bool}>}
     */
    #[Computed]
    public function schedule(): array
    {
        $tasks = array_map(fn (array $task): array => [...$task, 'next' => Carbon::parse($task['next'])->diffForHumans()], ScheduledTasks::all());

        return ['heartbeat' => app(Heartbeat::class)->last()?->diffForHumans(), 'tasks' => $tasks];
    }

    /**
     * The doctor rows with their translated status.
     *
     * @return list<array{key: string, label: string, status: string, color: string, message: string}>
     */
    #[Computed]
    public function doctor(): array
    {
        return array_map(function (array $row): array {
            $status = CheckStatus::from($row['status']);

            return [...$row, 'status' => $status->label(), 'color' => $status->color()];
        }, $this->doctorRows ?? []);
    }
};
```

```php
namespace App\Actions\Audit;

use Illuminate\Support\Facades\Context;

/**
 * Which Artisan command is running, for the audit log (CD-7, RL-9). Hidden context: never written to the logs,
 * carried into the jobs a command dispatches, and replaced per job by a queue worker, so a worker's jobs keep the
 * origin they were dispatched with. A nested Artisan::call() keeps the outer command.
 */
final class ConsoleOrigin
{
    public const string CONTEXT_KEY = 'audit.console_command';

    /** @var list<string> commands that only run other work; they are never an entry's origin */
    public const array WORKERS = [
        'queue:work', 'queue:listen', 'schedule:run', 'schedule:work', 'schedule:test', 'horizon', 'horizon:work', 'octane:start',
    ];

    public static function enter(?string $command): void
    {
        if ($command === null || $command === '' || in_array($command, self::WORKERS, true) || self::command() !== null) {
            return;
        }

        Context::addHidden(self::CONTEXT_KEY, $command);
    }

    public static function leave(?string $command): void
    {
        if ($command !== null && self::command() === $command) {
            Context::forgetHidden(self::CONTEXT_KEY);
        }
    }

    public static function command(): ?string
    {
        $command = Context::getHidden(self::CONTEXT_KEY);

        return is_string($command) ? $command : null;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Console\Concerns;

use Symfony\Component\Console\Input\StreamableInputInterface;

/**
 * Reads secrets from standard input (CD-8, RL-10), so they never appear in the process list or the shell history:
 * `printf '%s\n' "$PASSWORD" | php artisan …`. Tests set the stream with Input::setStream().
 */
trait ReadsStandardInput
{
    /** The first line of standard input without its line ending; null for an empty line or a closed stream. */
    protected function firstLineOfStandardInput(): ?string
    {
        $stream = $this->standardInput();
        $line = $stream === null ? false : fgets($stream);

        if (! is_string($line)) {
            return null;
        }

        $line = rtrim($line, "\r\n");

        return $line === '' ? null : $line;
    }

    /** All of standard input; null when it is empty. */
    protected function allOfStandardInput(): ?string
    {
        $stream = $this->standardInput();
        $contents = $stream === null ? false : stream_get_contents($stream);

        return is_string($contents) && trim($contents) !== '' ? $contents : null;
    }

    /** @return resource|null */
    private function standardInput()
    {
        $stream = $this->input instanceof StreamableInputInterface ? $this->input->getStream() : null;

        return $stream ?? (defined('STDIN') ? STDIN : null);
    }
}
```
